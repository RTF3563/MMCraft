# 정품 로그인 승인 받기 (한 번만)

**결론: Azure에 앱을 등록하고 → Client ID를 Mojang 신청서로 보내 → 승인되면 GitHub에 Client ID 한 줄 등록. 승인 전에는 런처 로그인이 되지 않습니다.**

새로 만든 런처는 Minecraft 로그인 API를 쓰려면 Mojang 승인을 따로 받아야 합니다 (승인 전에는 `403 Invalid app registration`).

## 1. Azure 앱 등록 (약 10분)
0. **먼저 무료 Azure 계정 만들기** (개인 Microsoft 계정으로 바로 portal.azure.com에 들어가면 `AADSTS16000 ... tenant 'Microsoft Services'` 오류가 남)
   - 시크릿 창에서 https://azure.microsoft.com/free/ → 무료로 시작 → 같은 Microsoft 계정으로 가입 (본인 확인용 카드 입력이 나올 수 있음)
   - 가입이 끝나면 내 디렉터리(테넌트)가 생김 → 그 뒤 portal.azure.com 로그인
   - 그래도 같은 오류면 오른쪽 위 프로필 → **디렉터리 전환**에서 새 디렉터리 선택, 또는 `https://portal.azure.com/<내 디렉터리 주소>.onmicrosoft.com`으로 접속
1. https://portal.azure.com 접속 → Microsoft 계정으로 로그인
2. 검색창에 **App registrations**(앱 등록) → **New registration**
   - Name: `MMCraft Launcher`
   - Supported account types: **Personal Microsoft accounts only** (개인 Microsoft 계정만)
   - Redirect URI: 플랫폼 **Public client/native (mobile & desktop)**, 주소
     `https://login.microsoftonline.com/common/oauth2/nativeclient`
   - **Register**
3. 만들어진 화면의 **Application (client) ID** 복사 (예: `1a2b3c4d-....`)
4. 왼쪽 **Authentication** → 맨 아래 **Allow public client flows** = **Yes** → Save

## 2. Mojang에 사용 신청
- 신청서: https://aka.ms/mce-reviewappid (설명: https://help.minecraft.net/hc/en-us/articles/16254801392141)
- 적을 내용
  - Client ID: 위에서 복사한 값
  - 용도: 개인 모드팩(MMCraft) 전용 Java Edition 런처. Microsoft 로그인으로 정품 확인 후 게임 실행만 함
  - 저장소: https://github.com/RTF3563/MMCraft
- 결과는 메일로 옵니다 (보통 며칠~몇 주).

## 3. 승인되면 Client ID 등록
GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables 탭 → New repository variable**
- Name: `MMCRAFT_AZURE_CLIENT_ID`
- Value: Client ID

그다음 런처 버전을 올려 다시 배포하면 (`package.json`의 version을 올리고 `v1.0.1` 같은 태그) 플레이어 런처가 자동 업데이트되며 로그인이 켜집니다.
Client ID는 비밀번호가 아니라서 공개돼도 괜찮습니다.
