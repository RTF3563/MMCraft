# MMCraft 서버 런처 — 확정된 의도 (2026-11-21)

> 인터뷰로 확정한 내용. 구현은 새 세션에서 이 문서를 기준으로 진행.

## 목표 (Why)
- 모드팩·런처는 자동 업데이트되는데 **서버팩만 손으로 업데이트해야 하는 문제**를 없앤다.
- 사람이 손대지 않아도 서버가 **플레이어 런처와 같은 팩 버전**으로 스스로 업데이트·재시작되어 계속 돌아가게 한다.

## 대상 (Who)
- 서버 전용 **Windows PC**에서 MMCraft 서버를 여는 나(운영자). 서버 PC에 MMCraft(플레이어 런처) 설치는 필요 없음.

## 결과물
- **창이 있는 MMCraft 서버 런처** (Windows, 한국어/English, MMCraft 런처와 같은 디자인: 도트 글꼴·돌 버튼 등)
  - 서버 콘솔 로그, 접속자 목록, 시작/정지, 명령어 입력창, 메모리·포트 설정
- 소스는 **MMCraft 저장소 안에 함께** (예: `src/server-launcher/`) → 팩 버전 확인·모드 다운로드·버전 규칙(`nextPackVersion`) 코드를 런처와 공유
- 설치 파일 **`MMCraft-Server-Setup.exe`**: `MMCraft-Setup.exe`와 같은 Releases에 나란히 올림 + 사이트(mmcraft.dpdns.org)에 **"서버 런처 다운로드"** 버튼 추가

## 기능
1. **업데이트 감지**: 런처와 같은 팩 버전(`pack-dist` index.json)을 같은 시기에 확인
2. **업데이트 흐름** (서버 구동 중)
   - 공지 → **30초 카운트다운**
   - 전원 **킥** (밴 아님), 사유: "서버 업데이트가 있습니다. MMCraft를 재실행하여 업데이트를 진행해 주세요."
   - 서버 정지 → **월드 백업** → 모드·설정 교체 → 자동 재시작 (**월드 유지**)
3. **서버 모드 구성**: 팩 모드 중 **클라이언트 전용 자동 제외**, Fabric 서버 자동 설치
4. **크래시 자동 재시작**: 크래시·알 수 없는 종료 시 재시작. 사용자가 직접 정지하면 재시작 안 함. 짧은 시간에 연속 크래시면 무한 반복하지 않고 멈추고 알림
5. 처음 실행 시 **Mojang EULA 동의** 받기
6. **Windows 시작 시 자동 실행**: 옵션으로만, **기본 꺼짐** (운영자가 다른 서버도 열기 때문)

## 완료 기준 (Success)
- 새 팩 버전이 배포되면 사람 손 없이 서버가 그 버전으로 다시 켜지고, 런처로 업데이트한 플레이어가 바로 접속할 수 있다.

## 하지 않을 것 (Out of scope)
- 서버 호스팅 업체(패널) 방식, 리눅스 지원
- MMCraft 외 다른 서버 관리
- 한 PC에서 MMCraft 서버 여러 개 동시 구동
- 플레이어 밴·화이트리스트 관리 화면 (명령어 입력창으로 처리)
- Windows 시작 시 자동 실행을 기본으로 켜기
